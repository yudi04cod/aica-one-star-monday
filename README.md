# One Star for Monday

Entry for the [One Star for Monday](https://make.fun/c/u-clever-harbor-75-one-star-for-monday-9ead4a61) competition on [make.fun](https://make.fun).

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`: a one-star review of Monday, written as though Monday were a restaurant — 19 words, no explanation attached.

> One star. The server brought the wrong week, the food was cold, and the bill cost my whole weekend.

Run it with:

```sh
python3 main.py
```
